# 雨课堂课件打印导出 PDF（本机浏览器实践）

2026-11-02 实测总结：从长江雨课堂"学习内容"页把课件完整导出为 PDF。适用：需要保留公式、波形、例题解答的整页课件（文字提取无法还原图片公式时）。已验证对绪论、概念-1/2、时域分析-2、频域分析-1/2 共 6 份课件成功。

## 1. 目标页面 URL 规律（学生端，classroom_id=25065612 为例）

| 页面 | URL |
|---|---|
| 课程列表（我听的课） | `https://changjiang.yuketang.cn/v2/web/index` |
| 学习内容页 | `https://changjiang.yuketang.cn/v2/web/studentLog/{cid}?classroom_id={cid}&tab=content&university_id=3612&platform_id=3` |
| 学习日志页 | 同上 `tab=log` |

| 课堂回顾页（易误入，非课件） | `https://changjiang.yuketang.cn/v2/web/student-lesson-report/{cid}/{lesson_id}/{card_id}` |
| 打印预览 | `https://changjiang.yuketang.cn/web/print`（固定 URL，会话内决定打印哪个课件） |

- 学习内容页每条学习单元前有类型标签：`课堂`（签到/回顾，无课件）、`课件`（PPT 可打印）、`微课视频`（视频，一般 1 页封面，可打印但无意义）。

- 课堂项点击后进入 `student-lesson-report`（课堂回顾），**这不是课件**，别在里面找打印课件。

## 2. 打印导出标准流程（本机浏览器 Edge + cu 坐标）

在"学习内容"页点击目标课件行 → 课件查看器 → 打印课件 → 打印预览 → 触发浏览器打印 → 另存为 PDF。坐标为本机 1920×1080 全屏窗口的千分比（0-1000），窗口变化需重截图校准：

1. **学习内容页**：点击课件名称行（名称区域 x≈314-454；y 依列表位置，操作前截图校准）。
2. **课件查看器**：点击右上「打印课件」≈ `(887, 92)` → 等待约 10 秒进入 `/web/print`。
3. **打印预览（雨课堂样式面板）**：左侧「打印」按钮 ≈ `(63, 865)`。点击后可能有两种结果：
   - **Chromium 打印预览**（常见）：打印机已是「另存为 PDF」、页面「全部」，左下「保存」≈ `(57, 935)`；
   - **系统打印对话框**（偶发）：WPS"另存为 PDF"保存 ≈ `(50, 935)`。
4. **Windows「另存为」对话框**：
   - 路径记忆：上次保存目录会自动保留（本任务为课件 PDF 目录），直接确认即可；
   - 文件名框 ≈ `(128, 328)` 一带（OCR 校准），点它 → `Ctrl+A` → 输入新文件名（不必带 .pdf 后缀）→ 点「保存(S)」≈ `(305, 402)`；
   - 保存成功后浏览器右上下载面板会出现该 PDF（点「打开文件」可预览验证）。
5. **验证**：`pypdf`/`PyPDF2` 读页数应与课件大纲页数一致；抽查 1-2 页确认公式/波形非空白。

## 3. 本机浏览器（seed_computer_use, cu）操作要点

- **用 Edge，不要用 Chrome**：用户实际使用 Edge。误开 Chrome（含 `--restore-last-session`）恢复的是用户业务标签且雨课堂登录态丢失；Edge 重启后雨课堂登录态也可能失效（会话 cookie），需要重新扫码。
- **启动应用**：`cu.launch_app` 需传字符串名（如 `Microsoft Edge#<hash>`），hash 从同 cell 的 `cu.list_apps()` 结果取；跨 cell 直接传名有时报 `NO_SESSION`，重试即可。
- **地址栏输入**：直接点击地址栏中部（y≈52）→ `Ctrl+A` → 输入/粘贴 → `Enter`。**长 URL 会被历史自动补全篡改**（曾把 classroom_id 改成 25065756 别的课）；必要时分段或用短 URL（先到 `changjiang.yuketang.cn` 再点进课程）。
- **坐标即千分比**：OCR 返回的 box 坐标（0-1000）与 `cu.click` 一致，**不要再除以屏幕尺寸**（曾因此误判"点击无效"）。
- **点击后必截图验证**：页面滚动/窗口大小变化会使旧坐标失效。学习内容页布局偶发整体偏移（+40 左右），稳妥做法是"导航 → 等待加载完成 → 截图 → 按最新 OCR 立即点击"。
- **避免误操作**：点窗口右上「最大化」按钮可能点到「关闭」把浏览器关掉（→ 重启后登录态丢失，需重扫）；尽量用页面内元素/地址栏完成导航。

## 4. 登录机制（扫码版，与 SKILL.md 微信快捷登录并存）

- Chrome/Edge 重启后雨课堂可能退回登录页：`https://changjiang.yuketang.cn/web/?next=...`。
- **本机虚拟桌面（cu 操作的 Edge）打开登录页**：点「微信快捷登录」文本链接 → **等待 3–4 秒** → 页面自动出现「已验证，可直接快捷登录」按钮（本机微信已登录、浏览器已检测到）→ 点击即登录，**无需扫码**。若按钮未出现，先确认本机微信在线再重试。
- 页面勾选框「我已阅读并接受雨课堂用户协议、隐私政策」在**文字左侧**；点文字本身会打开协议页，需浏览器后退。
- 二维码方式（备用）：出现「二维码已失效」时点「重新获取」刷新；扫码登录也可行，但本机已登录微信时快捷登录更省事。

## 5. 死路与教训（勿重复踩）

| 方案 | 结果 |
|---|---|
| bu 环境 `CDP Page.printToPDF` | 报 `Session with given id not found`，不可用 |
| bu 触发系统打印对话框 | `wait_for_download`/`Ctrl+P` 无效，打印必须本机浏览器或 request_action 接管 |
| 本机地址栏直接输长 URL | 被历史建议篡改 classroom_id，导航到错误课程 |
| 点击课程卡片"无反应" | 根因是把 OCR 千分比坐标又除以屏幕尺寸；用原值即正常 |
| 点「最大化」 | 曾误关浏览器窗口，登录态丢失 |
| cu.launch_app 单独调用 | 偶发 `NO_SESSION`，需与 list_apps 同 cell 或重试 |
| OCR 异常（全屏重复框） | 打印预览页偶发，等页面稳定重截图即可 |
