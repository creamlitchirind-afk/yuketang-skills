# 课件阅读推进与课堂报告取题（学生端实测）

2026-11-03 ~ 2026-11-08 实盘沉淀。这两件事都在学生端页面里做，但入口和交互完全不同：课件是"看页面推进度"，课堂报告是"进报告页读列表"。混用入口是最常见的浪费。

## 1. 三条链路的入口区分

| 目标 | 正确入口 | 常见错法 |
|---|---|---|
| 逐页阅读推进课件进度（如 24/46） | 学习内容页 `tab=content` → 点课件名 → `studentCards/{cid}/{course_id}/{card_id}/ppt` | 去课堂回顾页里找课件 |
| 看某次课堂的习题 / 回放 | 课程卡片 → 学习日志 `tab=log` → 筛选"课堂" → 点目标课堂 → `student-lesson-report/{cid}/{lesson_id}/{card_id}` | 直接访问报告页 URL（返回"页面不存在或学习内容被删除"） |
| 导出整份课件 PDF | 课件查看器右上"打印课件" → `/web/print` | 见 [print-and-export.md](print-and-export.md) |

关键区分：**课堂回顾页不是课件**，里面没有 PPT 翻页；**课件查看器里也没有课堂习题**。两者 URL 前缀只差一段，容易看串。

## 2. 课件查看器翻页与内嵌选择题（2026-11-11 修订，已推翻旧的"只能滚动"结论）

### 2.1 计页规则（用户口径 + 两次实测确认）

1. 在正文区**向下滚动一定距离**即可翻到下一页；
2. 每页**停留约 3 秒**即被记为完成、进度 +1（实测留 4 秒更稳）；
3. 进度不涨通常不是"翻页没生效"，而是**当前那一页是内嵌选择题**，必须先作答、把选项选上，系统才放行。
4. 唯一验收判据：页面顶部「学习进度：N/M」的数字变化；"页面内容换了"不算成功。

### 2.2 翻页手段优先级（按实测成功率）

| 手段 | 效果 | 说明 |
|---|---|---|
| **键盘 PageDown / PageUp** | ✅ 最稳 | 一次前进/后退 1 页，停留 ≥4 秒计页。注入用 `keybd_event`，`PageDown`=VK_NEXT `0x22`、`PageUp`=VK_PRIOR `0x21`（`cu.press("down")` 之类在本机对课件无效） |
| 正文区滚轮 | ⚠️ 不稳定 | 1–4 格可能完全不翻，也可能一次跳 3 页；跳过的页因停留不足 3 秒**不计页**，所以别用滚轮快扫 |
| 点左侧大纲缩略图 | ⚠️ 能换页、**不计页** | 实测点第 27、29 页后进度原地不动；缩略图高度随内容变化，坐标每次要重新截图取 |
| 点内容区 / 方向键 / 空格 | ❌ | 无效，不要再试 |

### 2.3 内嵌选择题页：识别与作答（可直接完成，不必交回用户）

- **识别**：PageDown 突然按不动，页面顶部出现「单选题 1分」标签页头，正文是题干 + Ⓐ/Ⓑ/Ⓒ/Ⓓ + 右下角蓝色「提交」按钮。这类页读秒也不计页，只有作答才放行。
- **作答步骤**：算出答案 → 点选项圆圈（点选项文字同样可以）→ 点右下「提交」→ 页面自动前进，进度 +1。实测**多数环境里正文区鼠标点击可以直接生效**，无需人工接管。
- **定位卡住的那一页**：① 大纲缩略图上带蓝色「未读」角标的页 = 还没计页的页，按角标定位最省事；② 或从末页 `PageUp` 回退若干页，按标题找到题干页。
- **点击"没反应"时的排查顺序**（几乎都是环境问题，不是平台限制）：
  1. 有残留 PowerShell 控制台 / 对话框 / 扩展面板压在浏览器上 → 它会吃掉点击与键盘，先清掉（Session 3 内 `Stop-Process` 整批结束）；
  2. 浏览器未最大化或不在前台 → `ShowWindow(h,3)` + `SetForegroundWindow`（脚本开头做，别在脚本里再抢前台）；
  3. 坐标取自过期截图 → 重新截图、重新取点；
  4. 排查后重试，通常第二次即可选中并提交成功。

### 2.4 其它坑

- 顶部约 `(885,50)` 是浏览器扩展区域，点了会弹扩展面板遮挡画面；点页面空白处关闭。
- `F5` 刷新课件页会把视图退回第 1 页，但进度数字不回退；别用刷新做"进度同步"。
- 残留控制台是最大噪声源：跑脚本要先把控制台切前台再输入执行，脚本内先最大化并置前浏览器，跑完 `; exit` 或事后整批清进程。


## 3. 课堂报告页导航（不能直连 URL）

正确链路：

1. 登录后进「我听的课」首页；
2. 点课程卡片 → 学习日志页 `studentLog/{cid}?classroom_id={cid}&tab=log`；
3. 顶部筛选切到「课堂」（`rain-tabs` 系列，按文本定位）；
4. 点目标课堂记录 → 进入 `student-lesson-report/{cid}/{lesson_id}/{card_id}`；
5. 报告页左侧「课堂回顾」下有「习题」「课件」筛选项，右侧是回放视频。

取题细节：

- 列表只显示题干摘要，**点题目条目才会弹窗展开选项详情**（可看 A/B/C/D 与作答状态）；只看列表无法确认选项。
- 题目标注形如 `P16`，对应课件第 16 页，可回课件查看器对照题干与公式原文。
- 滚动发生在**左侧列表区域**，不是整页滚动。

直连报告页 URL 的现象：即使已登录也会返回 errpage「页面不存在或学习内容被删除」，**容易误判成内容被删除**。2026-11-03 已确认这是入口问题，不是权限或删除。

## 4. 长任务与会话稳定性（最贵的教训）

- 一份 46 页课件一次读完属于长任务：2026-11-04 读到 `24/46` 时会话中断，Edge 被关闭后登录态一并丢失，剩余 22 页只能等桌面恢复后重来。
- `cu.switch_desktop("pip")` 重连在本机实测**连续失败**，不能当恢复手段反复重试；超过 2 次仍失败就停下来说明情况，不要空转。
- 因此开长任务前：先确认虚拟桌面在线、Edge 已登录雨课堂；把阅读**拆段**（如每 10 页一段），每段结束记录当前进度数字；中断后从记录页续读，不从头再来。
- 不要把长循环塞进单次调用（一次滚 40 页）。一次调用只推 1–3 页，每页单独截图校验。

## 5. 数据落点与验收

- 逐页阅读只改变进度数字，验收就是右上角 `N/M` 与目标一致，不产生文件。
- 课堂报告取到的题目 / 课件内容，归档到共享资料目录（如 `B:\07_学校学习\03_共享资料\<课程名>\`），题目标注 `P几` 便于回查原课件页。
- 作业即使已过截止时间仍可打开查看，但**提交与否必须由用户确认**；默认只读。
