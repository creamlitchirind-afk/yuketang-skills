# 雨课堂未完成巡检与汇报（yuketang-unfinished-watch）

> 这是定时任务「雨课堂未完成任务推送」的固化版。默认**只读**：不提交作业、不签到、不点答题、不改任何学习数据。

## 0. 一句话规则

**每轮先归并课程数（N 门课 / M 个班次），再逐班次扫描未完成；只报仍可完成的项，不可做的一律不出现；没有可做项就报成绩构成。**

## 1. 输入与配置

工作目录示例：`<项目根>\ykt_watch\`

| 文件 | 作用 | 关键字段 |
|---|---|---|
| `baseline.json` | 上轮快照，用于判断“新增” | `items`（classroom_id → “类型/标题”数组，**只存可做项**）、`scope`、`course_names`、`last_scores`、`count_rule`、`updated_at` |
| `push_config.json` | 推送开关 | `channel`、`qmsg_key`、`enabled`、`fallback_file` |

- `enabled=false` 时**不发任何消息**，有新增只覆盖写 `fallback_file`。
- Qmsg 发送：`GET https://qmsg.zendee.cn/send/{key}?msg=<urlencoded>`，消息用 `[uri]::EscapeDataString` 编码。

## 2. 执行流程

### 2.1 课程发现（每轮必做）

1. `import aha_browser_use as bu`，先 `bu.list_tabs()`。
2. `bu.navigate("https://changjiang.yuketang.cn/v2/web/index?newWeb=1")`，等 6–9 秒。
3. 读「我听的课」区域文本，得到课程名 + 教师 + 班级；课程卡片通常不内嵌 `classroom_id`，需要靠已知映射或逐卡进入 `studentLog` 获取。
4. **按课程名归并同名不同班次**，得到 `N 门课`、`M 个班次`。

> 已知映射（2026-11 采集，账号或学期变化后需重采）：信号与系统 25065612 / 25065614；操作系统与应用 25065598 / 25065599；传感器技术 25065756 / 25065758；医学数据挖掘 25065626 / 25065627 / 25065628；移动应用系统开发 25065630 / 25065629；概率论与数理统计 25065738；临床医学概论（乙）25064801。

### 2.2 逐班次扫描未完成

对每个 `classroom_id`：

```
https://changjiang.yuketang.cn/v2/web/studentLog/{cid}?classroom_id={cid}&tab=log
```

1. 等待 5–6 秒；若落到 `/v2/web/forbidden` 或登录页 → 该班次跳过（不汇报、不解释）。
2. **不能直接带 `tab=unfinished`，会被重定向**。必须在页内对 `.rain-tabs__nav-item` 中文本含「未完成」的项派发五连合成鼠标事件（pointerdown / mousedown / pointerup / mouseup / click）。
3. 等 4–5 秒后读 `document.querySelectorAll('.unfinished-study__item')` 的 `innerText`，换行压成 `|`，保留类型（课件/图文/课堂/作业/试卷/讨论）、标题、截止时间、进度。

### 2.3 可做性过滤（口径）

以下**一律不算可做**，既不计数也不展示：

| 文案特征 | 含义 |
|---|---|
| 含「已超时」「已截止」 | 平台关闭，无法补 |
| 课堂条目含「未签到」 | 历史课堂，签到已结束 |
| 课堂条目显示「上课中」且开课时间已过 | 签到窗口已过，无法补签 |
| 课程打不开 / 无权限 / 不在当前账号 | 不可检查 |

### 2.4 与基线比对

- 本轮出现的条目在 `baseline.json` 的 `items[cid]` 中不存在 → 新增。
- 写回时 `items` **只存可做项**；新出现的班次自动加入 `items` 与 `scope`；`updated_at` 写本轮时间。

### 2.5 推送

- 无新增 → 不发消息。
- 有新增且 `enabled=true` 且 `qmsg_key` 非空 → 只发一条汇总：
  `雨课堂新增待办 N 项` + 每条 `课程名 · 类型 · 标题 · 截止时间`。
- 有新增但 `enabled=false`（或 key 为空）→ 同内容覆盖写 `fallback_file`。

## 3. 汇报版式（用户 2026-11-23 定稿）

1. **第一行固定**：`共 N 门课（M 个班次）`，来自本轮实时归并，不得写死。
2. **分课分节**：按课程名归并；同名多班次的可做项去重合并到同一节。
3. 条目格式：`类型｜标题｜截止时间（剩 N 天）`；新增项行尾加「（新增）」。
4. 不可做项、无权课程、扫描条数、剔除明细、推送开关状态**全部不展示**。
5. 某门课没有可做项 → 该节整节不出现。
6. **全部课程都没有可做项** → 改报成绩构成，一门课一行：
   `课程名：总分（模块 得分/满分 · …）`，模块含作业、雨课堂课件、课堂、AI学伴使用、考试等，从各课「成绩单」页读取。
7. 结尾只有存在需用户本人处理的项时，写一行 `需你本人处理：…`；否则不写套话。

### 汇报样例

```
共 9 门课（12 个班次）

**信号与系统**
- 开放型作业｜多域分析体系的本质梳理｜11-25 10:30（剩 2 天）

**操作系统与应用**
- 试卷｜第6次作业｜11-27 11:34（剩 4 天）

需你本人处理：上面两件
```

无待办时：

```
共 9 门课（12 个班次）
- 信号与系统：77.4（作业 52.6/70 · 课件 9/10 · 课堂 5.769/10 · AI学伴 10/10）
- 操作系统与应用：48.9（作业 19.14/33 · 课堂 19.627/33 · 考试 10.12/23）
```

## 4. 成绩构成读取

`https://changjiang.yuketang.cn/v2/web/studentLog/{cid}?classroom_id={cid}&tab=student_school_report&university_id=3612&platform_id=3`

- 总分：正文正则 `成绩概况\s*([\d.]+)`。
- 模块小计：正则 `([\u4e00-\u9fa5A-Za-z]{2,8})\s*(\d+)个单元，共([\d.]+)分\s*个人得分：\s*([\d.]+)`。
- 「未批改 ≠ 0 分」：主观题未批改时显示 0.000，不要当成交白卷。

## 6. 已知坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 带 `tab=unfinished` 打开又跳回日志页 | 平台重定向 | 先到 `tab=log`，再点「未完成」标签 |
| 未完成列表为空但页面有数字 | 标签未真正切换 | 用五连合成鼠标事件而不是 `.click()` |
| 打不开课程 / 落 `/v2/web/forbidden` | 账号切换或不在该班 | 跳过，不汇报，不切账号 |
| 标签越开越多导致内存爆满 | 多标签堆积 | 单标签复用，处理完即关 |
| 登录态丢失 | 会话过期 | `interaction_request_action(type="browserControl")` 请用户扫码，禁止代操作 |
| 登录后页面显示名与学籍不一致 | 多账号 | 以页面实际课程列表为准 |
